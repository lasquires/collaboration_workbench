# Research Workspace

A separate local application for evidence-driven software reconstruction, with
Git-connected projects, scoped tasks, source provenance and collaborative research.

This repository was extracted from the SSG2 prototype. Independent packaging,
project onboarding and dual Git synchronization are being completed. The current
source still contains legacy names and compatibility routes; this is not yet a
ready-to-install release.

See `docs/superpowers/specs/2026-11-13-standalone-git-workspace.md` and the matching
implementation plan for the application boundary and delivery gates. Project
agents will use a published setup guide and configuration contract rather than
copy application code into their project.

No project database, game assets or native binaries are included here.
