# Explicit journal sharing review

The user authorized finishing the existing separate Git/live collaboration app and backend-first execution. This slice closes its existing authored-journal privacy blocker; it does not change source-project authority.

## Design

Keep original task_journal_entries and local events immutable. A current local reviewer explicitly selects a derived redacted disclosure or an omission notice for each unsafe journal on a bounded review page. The preview returns only source IDs/hashes and proposed safe public values, never the matched private text. Global project revision and review digest pin every choice. Review receipts stay installation-local and are never inferred from imported disclosures. Once a disclosure is published, its immutable history remains; a later choice cannot erase earlier publication.

Redaction replaces each unsafe authored string value in structured journal details with `[LOCAL_PATH_REDACTED]`, preserving safe sibling fields. Nested JSON strings are decoded and projected recursively. Unsafe object keys or attribution/identity metadata are not silently rewritten. Omission publishes an explicit notice. Public wrappers retain original task/event/installation identity, source SHA-256 and original actor attribution, but never pretend the sanitized bytes hash to the original event. Both modes are derived disclosure, not original evidence or authenticated forensic review.

Generated host roots, raw blobs, credentials and unsupported non-journal prose keep existing failclosed serialization. Legacy safe notes and bundle hashes remain readable. Incoming disclosures cannot authorize projection of an unsafe original that exists on the receiving installation.

## Fixed worker interface

Worker owns only tools/workspace_journal_projection.py and tests/test_workspace_journal_projection.py. Export `POLICY_VERSION=1`, `COLUMNS` tuple, `unsafe_journal(row, known_roots=())->bool`, `project_journal(row, mode, known_roots=())->dict`, `validate_disclosure(row)->None`. Error is ValueError (existing StoreError409 from pathgate may be caught internally). No DB writes. Use existing roadmap_research.canonical/digest and lazy existing roadmap_exchange._portable_path_check so path semantics agree. No implementation changes to either dependency.

Exact public columns: id, project_id, source_event_id, task_id, source_sha256, origin_store_id, mode, policy_version, details_json, source_actor_json, created_by, kind, recorded_at, historical_at, public_sha256. Mode is redacted or omitted. Nullable fields: source_actor_json, created_by, historical_at; all others required. Omitted details exactly {"notice":"Original journal entry withheld after explicit local review."}. For redacted details, preserve safe values/siblings and replace unsafe string leaves; nested JSON strings remain canonical JSON strings. Reject unsupported unsafe dictionary keys or public metadata rather than silently changing identities/attribution. Original raw input row must retain its source_event_json/hash and detail equality validated like existing exchange journal validation. `source_actor_json` comes from original source_event_json.actor_json. Other original metadata comes from the journal row. Wrapper public content is all columns except id/public_sha256; public_sha256=research.digest(content); id=str(uuid.uuid5(uuid.NAMESPACE_URL,'workbench-journal-disclosure:'+public_sha256)). Validate exact keys/types (bool is not policy int), canonical details/actor JSON, identity/hash, kind and safe public fields. Do not claim source_sha256 authenticates absent original bytes on receivers.
